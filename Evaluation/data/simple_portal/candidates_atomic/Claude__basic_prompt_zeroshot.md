### Requirement 1
Build a single-page portal homepage as a static site using only plain HTML, CSS, and vanilla JavaScript.

### Requirement 2
[The static site consists of] three files: index.html, style.css, app.js.

### Requirement 3
[Building the site involves] no frameworks or build step.

### Requirement 4
Use a horizontal top navigation bar.

### Requirement 5
[The top navigation bar has] no sidebar.

### Requirement 6
[The top navigation bar has] a brand/logo on the left.

### Requirement 7
[The top navigation bar has] the nav buttons on the right.

### Requirement 8
Include exactly four navigation buttons: Dashboard, Policies, History, Contact.

### Requirement 9
Clicking a button switches between four corresponding in-page views without reloading.

### Requirement 10
[When a button is active,] the active button is highlighted.

### Requirement 11
Style the navigation with rounded (pill-shaped) buttons.

### Requirement 12
Style the navigation with a blue accent color (filled blue for the active button, blue tint on hover).

### Requirement 13
Style the navigation with a modern font.

### Requirement 14
Apply a single consistent blue accent to all nav buttons.

### Requirement 15
Do not color [navigation] buttons individually by label.

### Requirement 16
Dashboard [view] is the main homepage with a greeting/clock.

### Requirement 17
Dashboard [view has] a web search bar.

### Requirement 18
Dashboard [view has] an app launchpad (link tiles).

### Requirement 19
Dashboard [view has] a daily quote widget.

### Requirement 20
Dashboard [view has] quick tasks with add/check/delete.

### Requirement 21
Dashboard [view has] at-a-glance stats.

### Requirement 22
Persist [Dashboard] tasks in localStorage.

### Requirement 23
Policies [view] is a set of informational cards (e.g., Returns, Shipping, Privacy, Warranty).

### Requirement 24
History [view] is a list of recent activity / past orders.

### Requirement 25
Contact [view] is a contact form with name, email, and message fields.

### Requirement 26
[The Contact form has] validation.

### Requirement 27
[The Contact form shows] a confirmation message on submit.

### Requirement 28
[Use a] light theme only.

### Requirement 29
Do not include any dark theme.

### Requirement 30
Do not include a theme toggle.

### Requirement 31
Make it polished and responsive.

### Requirement 32
[Make it have] a clean modern aesthetic (glassmorphic cards, subtle animations) consistent with the blue accent.
