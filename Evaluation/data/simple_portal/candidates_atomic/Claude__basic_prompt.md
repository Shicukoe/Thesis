# Claude__basic_prompt - candidate atomic decomposition (mode=candidate, keep-all, verbatim, hand/not-GT-blind preview)

### Requirement 1
Build a single-page portal homepage as a static site using only plain HTML, CSS, and vanilla JavaScript (three files: index.html, style.css, app.js) - no frameworks or build step.

### Requirement 2
Use a horizontal top navigation bar (no sidebar) with a brand/logo on the left and the nav buttons on the right.

### Requirement 3
Include exactly four navigation buttons: Dashboard, Policies, History, Contact.

### Requirement 4
Clicking a button switches between four corresponding in-page views without reloading; the active button is highlighted.

### Requirement 5
Style the navigation with rounded (pill-shaped) buttons, a blue accent color (filled blue for the active button, blue tint on hover), and a modern font.

### Requirement 6
Apply a single consistent blue accent to all nav buttons (do not color buttons individually by label).

### Requirement 7
Dashboard is the main homepage: greeting/clock, web search bar, an app launchpad (link tiles), and widgets (e.g., daily quote, quick tasks with add/check/delete, at-a-glance stats). Persist tasks in localStorage.

### Requirement 8
Policies is a set of informational cards (e.g., Returns, Shipping, Privacy, Warranty).

### Requirement 9
History is a list of recent activity / past orders.

### Requirement 10
Contact is a contact form (name, email, message) with validation and a confirmation message on submit.

### Requirement 11
Light theme only - do not include any dark theme or theme toggle.

### Requirement 12
Make it polished and responsive, with a clean modern aesthetic (glassmorphic cards, subtle animations) consistent with the blue accent.
