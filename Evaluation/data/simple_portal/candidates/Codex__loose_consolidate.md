Create a portal homepage.

  Use a top navigation bar, not a sidebar. The navigation buttons should be:

  - Dashboard
  - Policies
  - History
  - Contact

  Style the navigation buttons as rounded buttons with a blue accent and a modern font.

  Apply these navigation button background color rules:

  - If the navigation button label starts with H, the background color should be blue.
  - If the navigation button label starts with O, the background color should be red.
  - If the navigation button label starts with D, the background color should be yellow.

  Do not include a dark theme.

  Add a contact form with:

  - Name field
  - Email field
  - Message field

  The email field must be validated before the form can submit.

  Make sure the page works well on mobile screens.
