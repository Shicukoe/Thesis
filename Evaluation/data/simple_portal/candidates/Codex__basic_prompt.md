Create a responsive static portal homepage using HTML, CSS, and JavaScript.

  Requirements:

  - Build a modern portal homepage, not a marketing landing page.
  - Use top navigation, not a sidebar.
  - Navigation buttons must be:
      - Dashboard
      - Policies
      - History
      - Contact

  - Style the navigation as rounded modern buttons with a blue accent and modern system font.
  - Apply these navigation color rules:
      - If a navigation button label starts with H, its background should be blue.
      - If a navigation button label starts with O, its background should be red.
      - If a navigation button label starts with D, its background should be yellow.

  - Do not include a dark theme.
  - Add a contact form with:
      - Name field
      - Email field
      - Message field
      - Submit button

  - The email field must be validated before the form can submit.
  - Make sure the page works well on mobile screens:
      - Top navigation should wrap or stack cleanly.
      - Content should collapse into single-column layouts.
      - Buttons and form fields should remain readable and tappable.
      - Avoid text overflow or layout overlap on narrow screens.

  - Keep the design polished, clean, and portal-like with dashboard sections, quick actions, status panels, announcements, and a usable first screen.
