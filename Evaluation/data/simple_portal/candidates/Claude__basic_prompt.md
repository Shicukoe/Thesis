Build a single-page portal homepage as a static site using only plain HTML, CSS, and vanilla JavaScript (three files: index.html, style.css, app.js) — no frameworks or build step.
Layout & navigation:
Use a horizontal top navigation bar (no sidebar) with a brand/logo on the left and the nav buttons on the right.
Include exactly four navigation buttons: Dashboard, Policies, History, Contact. Clicking a button switches between four corresponding in-page views without reloading; the active button is highlighted.
Style the navigation with rounded (pill-shaped) buttons, a blue accent color (filled blue for the active button, blue tint on hover), and a modern font. Apply a single consistent blue accent to all nav buttons (do not color buttons individually by label).
Views:
Dashboard — the main homepage: greeting/clock, web search bar, an app launchpad (link tiles), and widgets (e.g., daily quote, quick tasks with add/check/delete, at-a-glance stats). Persist tasks in localStorage.
Policies — a set of informational cards (e.g., Returns, Shipping, Privacy, Warranty).
History — a list of recent activity / past orders.
Contact — a contact form (name, email, message) with validation and a confirmation message on submit.
Theme: Light theme only — do not include any dark theme or theme toggle.
Make it polished and responsive, with a clean modern aesthetic (glassmorphic cards, subtle animations) consistent with the blue accent.
