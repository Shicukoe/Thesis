• Create a portal homepage.

  Use top navigation instead of a sidebar.

  Add navigation buttons:

  - Dashboard
  - Policies
  - History
  - Contact

  Style the navigation buttons with:

  - Rounded buttons
  - Blue accent
  - Modern font

  Navigation button background color rules:

  - If the label of the navigation button starts with H, the background color of the button should be blue.
  - If the label of the navigation button starts with O, the background color should be red.
  - If the label of the navigation button starts with D, the background color should be yellow.

  Do not include a dark theme.

  Add a contact form with:

  - Name field
  - Email field
  - Message field

  The email field must be validated before the form can submit.

  Make sure the page also works well on mobile screens.
